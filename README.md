# Overseas Income Tax — 境外收入税务申报 Claude Code SKILL

一个 [Claude Code](https://claude.ai/code) 技能（SKILL），帮**中国税务居民**把**美国来源收入**和**香港来源收入**一键折算为人民币、计算应补缴个人所得税，并生成格式化 Excel 申报表。

把繁琐的跨境税务计算（1042-S 解析、银行月结单解读、汇率折算、税收抵免）变成一句话。

## ✨ 它能做什么

- 📄 自动解析 **IRS Form 1042-S**（美国来源收入及预扣税）
- 📊 自动解析**美股券商年度报表**（股息、经纪商利息）
- 🏦 自动解析**香港银行月结单**（定期存款利息、储蓄活期利息）
- 💱 联网查询**中国人民银行汇率中间价**折算人民币
- 🧮 计算利息/股息/红利所得（**20% 税率**）的应补缴税额和境外税收抵免
- 📑 生成 4 个 Sheet 的**格式化 Excel 申报表**（按美国/香港分别统计）
- 🔒 支持**脱敏**（隐藏券商/银行名称）

## 🚀 使用方式

### 安装

把整个 `overseas-income-tax/` 文件夹放到：

- **全局**（所有项目可用）：`~/.claude/skills/overseas-income-tax/`
- **项目级**（仅当前项目）：`<项目>/.claude/skills/overseas-income-tax/`

### 使用

1. 把你的 PDF 材料放进一个文件夹：
   - IRS Form 1042-S
   - 美股券商年度报表（Activity Statement）
   - 香港银行月结单（全年 12 个月）

2. 在 Claude Code 里说一句话：

   > 帮我算一下今年的境外税务

Claude 会自动识别 PDF、提取收入、查汇率、算税、生成 Excel。

## 📋 适用范围

✅ 支持：
- 中国税务居民申报**美国来源**股息/利息（1042-S + 美股券商）
- 中国税务居民申报**香港来源**银行利息/股息

❌ 不支持（暂未覆盖）：
- 其他国家来源收入
- 资本利得（中国目前不抵减境外所得）
- 工资薪金等综合所得

## 🏗️ 设计理念

> **让 Agent 判断，脚本只做纯 I/O。**

脚本（`scripts/`）只负责 Agent 做不了的确定性操作（建虚拟环境、提取 PDF 文本）。所有需要理解和判断的环节——收入识别、归类、口径判断、金额计算、校验、Excel 生成——全部由 Claude 当场判断和写代码完成，和真人手工算税一致。这样能灵活处理任何特殊情况（新币种、新收入类型、用户临时改口径）。

### 三条铁律（防错核心）

1. **所有数字必须来自原始 PDF，禁止估算**
2. **利息数据禁止自行按天数/利率推算**，取月结单记载值
3. **生成 Excel 前必须按自查清单逐项核对**

## 🔐 隐私

- 本 SKILL **不收集、不上传**任何用户数据
- 所有解析和计算都在本地（你的 Claude Code 会话内）完成
- 汇率查询仅向搜索引擎发起请求查央行中间价
- 支持脱敏机构名称

## ⚠️ 免责声明

本工具计算结果**仅供参考**，不构成税务建议。最终以主管税务机关核定为准。复杂情况建议咨询专业税务师。

中国现行规则依据：境外利息、股息、红利所得适用 20% 比例税率（《个人所得税法》），境外已缴税额可按规定抵免。
