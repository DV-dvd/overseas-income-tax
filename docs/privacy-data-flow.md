# 隐私与数据流（V1 本地版）

| 环节 | 接收内容 | 保存期限 | 访问控制 |
|---|---|---|---|
| 浏览器 | 问卷、已核验经济事项、汇率、PDF 提取结果 | 当前页面生命周期；刷新或关闭后清除 | 当前操作系统用户 |
| 本地服务端 | 单次请求中的 PDF 字节、JSON 事实和计算结果 | 请求处理期间的内存；不建立业务数据库 | 默认仅监听 127.0.0.1 |
| 模型服务 | 无 | 无 | V1 禁用 |
| 持久存储 | 应用本身不保存业务数据；用户主动下载的 Excel 由用户管理 | 由用户决定 | 操作系统文件权限 |

## 数据最小化

- 不要求姓名、身份证号或完整金融账号。
- 证据摘要应避免复制完整账号等与计税无关的信息。
- PDF 只做文本提取；服务端不把内容写入日志或业务数据库。
- 页面和导出使用同一计算结果，日志不记录请求正文。

## 同意与删除

进入计算前分别取得隐私说明、免责声明和金融账户信息的单独同意。当前版本没有账户和持久化数据库，因此删除方式是关闭页面、结束本地进程，并由用户自行删除下载文件。

如果未来部署到远程服务器，必须先补充身份认证、TLS、加密存储、访问审计、保留期限、删除接口和供应商清单；本地版的隐私说明不能直接沿用。
