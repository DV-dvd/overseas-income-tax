# 香港银行月结单解析

月结单（Statement）按月出具，全年 12 份（如 `202501.pdf` ~ `202512.pdf`）。常见香港银行报表繁简中文混排，币种分 HKD / USD（及其他外币）账户。

## 定期存款利息（Time Deposit）

在"定期存款账户"（`TIME DEPOSIT ACCOUNT 定期存款賬戶`）章节找 `Placement 敘做`（开立）记录：

```
Placement 敘做
17SEP25 00009 M0317SEP25 17DEC25 USD 10,000.00 3.3500% 83.32 10,083.32
```

字段顺序：`敘做日 存款编号 存款期M月 起息日 到期日 币种 本金 年利率 利息金额 本金加利息`

**取值规则（铁律，详见 data-integrity.md）**：
- **利息金额 = 第 7 列，直接采用，禁止用 本金×年利率×天数/360 自行推算**
- 本金 = 第 5 列，到期金额 = 最后一列

**校验**：本金 + 利息金额 ≈ 到期金额（允许 ±0.01 四舍五入误差）。不一致则报警。

### 跨年问题

若定期存款**起息日在上一年、到期在本年**（如去年12月敕做、本年1月到期）：

- 月结单记载的是**全期利息**
- 处理原则：按"**实际到账日**"归入实际收到利息的年度。即钱在本年到账，则全额计入本年（前提是上一年未就该笔申报过）
- **不要自行按天数拆分到两个年度**（铁律2，详见 data-integrity.md）

## 储蓄活期利息（Savings）

在"储蓄账户"（`STATEMENT SAVINGS ACCOUNT 儲蓄(結單)賬戶`）章节找 `INTEREST 利息收入` 记录：

```
01APR25 0000INTEREST 利息收入 6.82 31,677.84
```

格式：`日期 序号 INTEREST 利息收入 利息金额 新余额`。**利息金额 = 倒数第二列**，直接取值。

逐月汇总全年各币种账户的利息。

## 币种识别（关键）

月结单文本是连续拼接的，单看一行无法判断币种。**必须向上回溯上下文找账户币种标记**：

```
USD05MAR25 Balance B/F 承上結餘 31,671.02   ← USD 账户段开始
...
01APR25 0000INTEREST 利息收入 6.82 31,677.84   ← 这笔属于 USD
```

```
HKD05APR25 Balance B/F 承上結餘 2,334.55     ← HKD 账户段开始
...
01APR25 0000INTEREST 利息收入 5.53 67,334.55  ← 这笔属于 HKD
```

识别方法：从 `INTEREST 利息收入` 行向上找最近的 `USD` 或 `HKD` 开头的 `Balance B/F` 行，确定币种。

## 预扣税

**香港不对银行存款利息征收预扣税** → 所有银行利息的境外已缴税额 = 0。

## 输出汇总

每份月结单解析后，应得到该月的：
- 定期存款利息（按笔，含本金/利率/利息/到期金额，供校验）
- 活期利息（按币种，HKD 和 USD 分开）

全年 12 份汇总后得到香港利息总收入。
