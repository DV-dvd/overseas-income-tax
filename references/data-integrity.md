# 数据核对与校验（Agent 自查清单）

本 SKILL 的首要价值是**数据准确**。历史上踩过的坑都源于"自己估算"，所以校验是硬性要求。

**校验由 Agent 读数据时逐项自查**（不是调脚本）。每读出一个数字，立刻在脑中/用 Python 核对下表对应项；不一致的回溯 PDF 原文，绝不含糊带过。

## 三条铁律

1. **所有数字必须来自原始 PDF，禁止估算**。每个金额都要能在某份 PDF 中找到原文出处，并在申报表中标注来源文件。
2. **利息数据禁止自行按天数/利率推算**。定期存款利息取月结单 `Placement 敘做` 记载值；活期利息取 `INTEREST 利息收入` 记载值。（历史教训：曾因自行按天数拆分一笔跨年定期存款利息，把全期利息算错。）
3. **境外已缴税额只能用有 1042-S 凭证的部分**。券商实际代扣多于 1042-S 的部分不能用于抵免，需另行向券商/IRS 处理。

## Agent 自查清单（逐项过一遍）

### 1042-S
- [ ] 每张表格：`gross income × tax rate/100 ≈ tax withheld`（允许 ±$0.50，因税额四舍五入）
- [ ] 按 form identifier 去重，表数 = 不同 identifier 数（Copy B/C/D 三联内容相同只算一张）

### 券商报表
- [ ] 每笔股息：`持股数 × 每股金额 ≈ 股息总额`（允许 ±$0.05）
- [ ] 每笔扣税：`股息 × 10% ≈ 扣税`（W-8BEN 协定税率，允许 ±0.5%）
- [ ] 逐笔加总 = 报表合计行

### 银行月结单
- [ ] 每笔定期存款：`本金 + 利息金额 ≈ 到期金额`（允许 ±$0.01）
- [ ] 每笔活期利息：直接取值，无计算
- [ ] 币种账户归类：每笔利息向上找到 `USD`/`HKD ... Balance B/F` 确认币种

### 跨表一致性
- [ ] 1042-S 合计收入 vs 券商报表合计收入：差异需解释（典型：SGOV 国债 ETF 在 IRS 算利息、券商算股息）
- [ ] 1042-S 合计扣税 vs 券商合计扣税：券商多扣部分无凭证，不能用于抵免

## 差异处理

发现任何校验失败：
1. **停下**，不要继续生成 Excel
2. 列出每一项不一致，回溯原始 PDF 文本核对
3. 若是 PDF 提取错误 → 修正解析后重提
4. 若是真实差异（如 SGOV 分类）→ 在申报表注释中说明，不算错误
5. 无法解释的差异 → 询问用户，不要臆断

## 输出要求

最终交付时附一份"数据溯源表"：每项收入列出
- 金额（原币）
- 来源文件 + 页码/章节
- 是否通过上表校验
