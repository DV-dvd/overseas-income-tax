# Excel 申报表生成指南（Agent 当场写代码）

本 SKILL **不预置 Excel 生成脚本**——实战中是 Agent 读懂 PDF、判断好每笔收入后，**当场写一段 openpyxl 代码**生成。这样能灵活处理 JSON 模板预见不到的特殊情况（多币种、新收入类型、用户临时改口径、脱敏与否）。

## 原则

- **Agent 自己写代码**：用 openpyxl，按汇总表+美国明细+香港明细+税额计算 4 个 Sheet 生成
- **边判断边生成**：金额、归类、口径差异都是 Agent 读 PDF 的结论，直接写进代码，不经过中间 JSON schema
- **算税也当场做**：用 Python REPL 算 `收入折人民币 × 20% − 抵免`，把结果直接写进 Excel

## 4 个 Sheet 的结构

### Sheet 1：境外收入申报汇总
- 顶部：姓名、身份证号、纳税年度
- 主体表：序号 | 来源国家/地区 | 收入类型 | 币种 | 收入金额 | 境外已缴税 | 备注/来源
- 按地区分块：美国（蓝底）+ 中国香港（绿底）
- 每地区一个小计行，最后总计行

### Sheet 2：美国收入明细
- 逐笔：序号 | 类别 | 具体项目 | 币种 | 金额 | 已扣税 | 税率 | 来源

### Sheet 3：香港收入明细
- 逐笔：序号 | 类别 | 具体项目 | 币种 | 金额 | 年利率 | 期间 | 来源

### Sheet 4：税额计算
- 境外收入折算人民币（逐项）
- 应纳税所得额 = Σ 各项 × 汇率
- 应纳税额 = 应纳税所得额 × 20%
- 境外税收抵免（美国已缴税折人民币；香港为 0）
- **实际应补缴个人所得税 = 应纳税额 − 抵免**

## 样式

清晰可读即可（表头加粗、数字右对齐用 `#,##0.00`、合计行加粗、必要时按地区/类型用底色区分）。具体字号、色值由 Agent 自行决定，不强制统一审美。

## 脱敏处理（用户可选）

若用户选择脱敏，生成时把机构名替换为通用表述：
- `Interactive Brokers` / `IBKR` → "证券账户"
- `盈透证券` → 不出现
- 银行名：通常保留（月结单本身就显示，且银行名无敏感性）；用户特别要求时再脱敏

## 执行步骤

1. Agent 已读完所有 PDF、完成归类和校验（见 workflow.md 步骤 1-5、data-integrity.md）
2. Agent 当场写一段 Python（用 setup_env.py 建好的 venv python 运行）：
   - `import openpyxl` + styles
   - 定义 `sc()` 单元格写入辅助函数、`fillrow()` 填充辅助函数
   - 按 4 个 Sheet 依次写入（金额用 Agent 读 PDF 得到的真实值）
   - `wb.save(输出路径)`
3. 生成后用 Python 读回抽查几个关键单元格，确认无误

## Windows 注意

调用 venv python 时加前缀避免中文 GBK 崩溃：
```bash
PYTHONUTF8=1 <venv_python> -X utf8 <agent写的脚本.py>
```
脚本开头加 `sys.stdout.reconfigure(encoding='utf-8', errors='replace')`。
