# Excel 导出

Excel 由 `exporter.py` 从固定引擎返回的同一个 `CalculationResult` 生成。导出层不得重新归类、重新算税或修改金额。

当前工作簿包含：

1. 范围内测算：税年、结果状态、规则快照、计算指纹和金额
2. 已核验经济事项：实际参与计算的事实与证据 ID
3. 分国抵免账：应纳税所得额、抵免限额、报表扣税、符合条件已缴税与采用抵免额
4. 待核验与规则：阻断项、汇率记录和官方依据

页面展示和 Excel 中的金额必须由同一结果对象产生。测试会读回工作簿并与结果对象逐项比较。存在范围外事项时，工作簿标题仍使用“范围内测算”，不得改成全年最终申报表。
