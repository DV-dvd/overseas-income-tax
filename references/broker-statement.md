# 美股券商年度报表解析

券商年度报表（Activity Statement，如 IBKR 的活动账单）记录全年的交易、股息、利息等。中文版常见标题"活动账单"/"账户年度报表"。

## 股息明细提取

在报表中找"股息"章节（中文报表为 `股息` 表头，英文为 `Dividends`）。每条记录格式：

```
2025-09-23 UNH(US91324P1021) 现金红利 USD 2.21 每股 (常规股息) 221.00
```

提取字段：派息日期、股票代码、每股金额、股息总额、是否"替代股息"。

在"代扣税"章节（`代扣税` / `Withholding Tax`）对应同一天的记录里有已扣税：

```
2025-09-23 UNH(US91324P1021) 现金红利 USD 2.21 每股 - US 税收 -22.10
```

## 税率交叉验证

W-8BEN 下中美税收协定，股息预扣税率通常为 **10%**。逐笔验证：

```
扣税 ≈ 股息金额 × 10%   （允许 ±0.5% 误差，因每股金额四舍五入）
```

偏差大的（如 TQQQ 替代股息 $0.86 扣 $0.09 = 10.5%）属正常，标注即可。**偏差 >2% 的要单独提醒用户核对**。

## 经纪商利息（关键，易错）

报表"利息"章节有贷方（收入）和借方（成本）两类，**不能净额申报**：

| 类型 | 中文标记 | 性质 | 是否申报 |
|------|---------|------|---------|
| 贷方利息 | `贷方利息` / `Credit Interest` | 账户现金余额的利息收入 | ✅ 申报为利息收入 |
| 借方利息 | `借方利息` / `Debit Interest` | 融资买入股票的借款成本 | ❌ 不申报（是投资成本） |

例如全年贷方 +$100.00、借方 -$80.00、净额 +$20.00，**申报收入只填 $100.00**（贷方合计），不填净额。

## 替代股息（Payment in Lieu of Dividend）

因股票借贷/融资融券，部分股息以"替代支付"名义发放。**税务待遇与正常股息相同**（同样按 10% 预扣），合并申报为股息收入即可，无需单独处理。

报表中标记为"替代股息的付款"/"Payment in Lieu"。

## 港股股息（通过券商代收）

若券商报表中有港股代码（如东亚银行 `23`、小米 `1810`、泡泡玛特 `9992` 等 SEHK 上市股票）的股息：

- **香港不对非香港居民征收股息预扣税** → 已缴税额 = 0
- 这部分收入归入"香港来源"，而非"美国来源"
- 1042-S 中**不包含**港股股息（非美国来源）

## 报表总计核对

报表末尾通常有合计行：
- `总数 股息 在 USD XXX.XX` —— 全年股息总额
- `代扣税款 -XXX.XX` —— 全年扣税总额

用合计行校验逐笔加总是否一致。
