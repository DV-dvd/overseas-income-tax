# 端到端工作流程

用户说一句话（如"帮我算 2025 年的境外税务"）后，严格按以下步骤执行。**不要跳步**。

> 设计原则：脚本只做纯 I/O（建环境、提取 PDF 文本）。**收入识别、归类、口径判断、金额计算、校验、Excel 生成全部由 Agent 当场判断和写代码**——和真人手工算税的方式一致。

## 步骤 1：准备运行环境

```bash
# 创建虚拟环境并安装依赖（一次性）。脚本会打印 venv python 绝对路径，记下来后续用。
python scripts/setup_env.py <工作目录>
```

## 步骤 2：提取 PDF 文本

```bash
# 逐个 PDF 提取文本到同目录 .txt（避免控制台 GBK 崩溃）
PYTHONUTF8=1 <venv_python> -X utf8 scripts/extract_pdf.py <某个.pdf>
```

提取后读 .txt 内容。**PDF 类型识别交给 Agent 判断**（看文本头部关键词）：

| 关键词 | 类型 | 解析规则文档 |
|--------|------|-------------|
| `Form 1042-S` / `Internal Revenue Service` | IRS 1042-S | `1042s-parsing.md` |
| `Activity Statement` / `活動賬單` / 股票代码(AAPL/TSLA…) | 美股券商报表 | `broker-statement.md` |
| `STATEMENT` / `戶口號碼` / `結單期` / `存款` | 香港银行月结单 | `bank-statement.md` |

## 步骤 3：向用户确认参数

用 `AskUserQuestion` 一次问清：

1. **纳税年度**（默认按 PDF 内容推断，如 2025）
2. **是否脱敏机构名称**（券商/银行名 → 通用表述；默认脱敏）
3. **纳税人姓名 + 身份证号**（写进申报表）

## 步骤 4：Agent 解析美国收入

按 `1042s-parsing.md` 读懂每张 1042-S，按 `broker-statement.md` 读懂券商报表。**Agent 自己判断**：
- 每张 1042-S 的 income code、毛收入、扣税（box 7a）
- SGOV 等国债 ETF 在 IRS 算利息、券商算股息的分类差异
- 券商贷方利息（收入）vs 借方利息（成本）
- 港股股息（通过券商代收，归香港来源）
- **境外已缴税额：只采用 1042-S box 7a**（即使券商实际代扣更多）

## 步骤 5：Agent 解析香港收入

按 `bank-statement.md` 读懂所有银行月结单。**Agent 自己判断**：
- 定期存款利息：直接取月结单 `Placement 敘做` 记载值，**不自行算**
- 储蓄活期利息：取 `INTEREST 利息收入` 记载值，向上找 `USD`/`HKD ... Balance B/F` 定币种
- 香港不征预扣税 → 已缴税 0

## 步骤 6：Agent 查汇率 + 算税 + 自查

1. 按 `exchange-rate.md` 用 WebSearch 查中国人民银行中间价（联网优先，失败问用户）
2. 用 Python REPL 当场算：`应纳税所得额 = Σ 收入 × 汇率`，`应补缴 = 应纳税所得额 × 20% − 抵免`
3. 按 `data-integrity.md` 的**自查清单**逐项核对（本金+利息=到期？扣税≈10%？明细加总=合计？）。不一致的回溯 PDF。

## 步骤 7：Agent 当场写代码生成 Excel

按 `generation-guide.md`，**Agent 自己写一段 openpyxl 代码**（不调预置脚本），用 venv python 运行，生成 4 个 Sheet 的申报表。金额直接用步骤 4-6 读到的真实值。

## 交互话术模板（引导用户）

材料不全时主动询问：
- "我需要看到你的 1042-S、券商年度报表、银行月结单。请把这些 PDF 放进一个文件夹，告诉我路径。"
- "你的月结单只有 6 个月，全年是 12 个月吗？"
- "我没找到 1042-S，你今年有没有美国来源的股息/利息？"

## 输入材料检查清单

- [ ] IRS Form 1042-S（可能多张，每张 Copy B/C/D 三联内容相同，去重）
- [ ] 美股券商年度报表（Activity Statement，含股息和利息明细）
- [ ] 香港银行月结单（全年 12 个月）
- [ ] （可选）境外已缴税额证明、1042-S 中文翻译件
