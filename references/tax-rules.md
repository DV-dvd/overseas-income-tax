# 境外利息与普通现金股息的 V1 规则

## 适用边界

固定引擎只处理中国税收居民已经核验的境外利息和普通现金股息。来源地、性质、金额、币种、境外已缴税额和证据定位必须完整。

资本利得、复杂理财、特殊居民身份、补报、更正、已有预缴、历史未抵免余额和境外退税等情况进入待核验清单。本工具不会据此判断“无需申报”。

## 分类所得税额

境外利息、股息、红利属于其他分类所得，不与境内对应所得合并，按适用规则分别单独计算。V1 规则快照使用 20% 比例税率。

```text
类别应纳税额 = 该类别已核验应纳税所得额（人民币） × 20%
```

## 分国（地区）抵免账

抵免按国家或地区核算，不逐笔机械地从每笔收入税额中扣除预扣税。

```text
该国其他分类所得抵免限额 = 该国其他分类所得依中国规则计算的应纳税额
本年采用抵免额 = min(符合条件的境外已缴所得税, 抵免限额)
```

报表显示扣税额不当然等于符合条件的已缴所得税。错缴或错征、协定不应征收、利息滞纳金罚款、已经返还或补偿的税款等不能直接纳入可抵免额。历史结转最长年限和具体使用顺序由适用规则处理；V1 遇到历史余额时阻断完整结论。

## 结果命名

- 全部事项在范围内且问卷完整：输出“范围内结果”。
- 存在范围外或待核验事项：输出“范围内测算 + 待核验清单”。
- 没有可计算事项：只整理材料。

任何情况下都不自动称为全年最终应补缴总额。
