# 中国个人所得税规则（境外收入）

## 所得类型与税率

境外**利息、股息、红利所得**属于"分类所得"，**适用 20% 比例税率**，**不并入综合所得**（不与工资等合并、不适用年度汇算的累进税率）。

本 SKILL 处理的收入全部归入此类：
- 美国股息、美国利息、券商贷方利息、券商代收的港股股息
- 香港银行定期存款利息、储蓄活期利息

## 应补缴税额计算

```
应纳税所得额（人民币）= Σ 各项境外收入 × 对应汇率
应纳税额 = 应纳税所得额 × 20%
应补缴税额 = 应纳税额 − 境外已缴税额（有凭证部分，折人民币）
```

**境外已缴税额只计有凭证的部分**：美国用 1042-S box 7a，香港利息/股息预扣税为 0。

## 境外税收抵免限额

抵免不能超过"同一笔收入按中国税法算出的税额"。即：

```
某国抵免限额 = 该国收入折人民币 × 20%
实际可抵免 = min(该国实际已缴税额折人民币, 该国抵免限额)
```

通常境外税率（美国股息 10%、香港 0%）低于中国 20%，可全额抵免。

## 分国不分项原则

按**国家/地区分别**计算收入和抵免，不同国家的盈亏不能互抵，同一国家内不同收入项目合并计算。

本 SKILL 输出两个地区：
- **美国**：股息 + 利息合并，已缴税用 1042-S
- **中国香港**：利息 + 股息合并，已缴税 = 0

## 输出格式

申报表最终呈现：

| 项目 | 金额（人民币）|
|------|------|
| 境外收入总额（应纳税所得额）| ¥X |
| 适用税率 | 20% |
| 应纳税额 | ¥X |
| 减：境外税收抵免（美国）| −¥X |
| 减：境外税收抵免（香港）| −¥0 |
| **实际应补缴个人所得税** | **¥X** |

## 注意事项

- 股票**交易损益**（资本利得）目前中国不允许抵减境外所得，本 SKILL 不计入收入
- 经纪商借方利息（融资成本）不计入收入
- 本计算结果供参考，最终以主管税务机关核定为准，建议提示用户"建议咨询专业税务师或税务机关确认"
